# 云开诗词新标签页
* 本插件是云开诗词新标签页（Legacy）的重构版本，新版精简了功能，优化了代码并提升了用户体验。

## 简介
* 在浏览器新标签页随机展示中国古诗词。
* 支持语言：简体中文。
* 所需权限：storage。

## 指南
### 切换间隔
* 诗词切换间隔默认为 1 小时，如果想立即切换诗词，可以点击“换一首”按钮，“换一首”按钮冷却时间为 5 分钟
### 诗词主题
* 新的诗词主题刷新后不会立即生效，必须等到下一个切换间隔才会生效
* 诗词主题使用今日诗词 API V1（古诗词 · 一言 API），随机性更高
* 智能主题使用今日诗词 API V2，相关性更高
### 自定诗词
* 自定诗词可用于显示用户自行输入的文字
* 若想关闭自定诗词，再次点击“自定义”按钮，在弹出窗口中点击“关闭自定诗词”按钮即可
* 诗词主题、切换间隔等偏好设置在自定诗词下不会生效
### 字体类型
* 本插件并未内置任何字体，字体的显示效果与浏览器和系统有关
### 专注模式
* 请先开启专注模式，才能选择白噪音
* 播放白噪音时请不要随意关闭、刷新页面，否则白噪音会停止播放
* 如果出现其它异常，请参考下方的异常处理
### 异常处理 ★
* 尝试 “重置设置” 按钮。注意 “重置设置” 将恢复初始设置，但会保留其他数据，例如倒数日和待办事项
* 若 “重置设置” 无法解决问题，尝试 “重置插件” 按钮。注意 “重置插件” 将清空插件所有数据并恢复初始设置
* 若 “重置插件” 无法解决问题，尝试关闭浏览器新标签页并清除浏览器缓存（此方法一般适用于所有浏览器插件）
* 若清除浏览器缓存无法解决问题，尝试卸载后再重新安装本插件（此方法一般适用于所有浏览器插件）
* 最后，请参考[建议反馈](Report.md "前往建议反馈")将遇到的问题进行反馈，感谢您的支持。

## Q&A
### 为什么此插件需要 Storage 权限？
答：Storage 权限用于存放用户的设置数据，所有操作均在本地实现，请放心使用
### 为什么有的按钮点击后有反应，有的按钮点击后没反应？
答：当鼠标移至按钮上时，鼠标指针变为手指形状的按钮才可点击，鼠标指针没有变化的按钮无法点击
### 为什么刷新后还是显示上一次的诗词？
答：本插件设置了请求时间间隔为 1 小时，只有超过切换间隔才会请求并显示新的诗词
### 为什么打开智能主题后显示的诗词经常是《春江花月夜》？
答：这是今日诗词 API V2 的流量限制机制，请耐心等待或者关闭智能主题
### 为什么出现了 Unexpected end of JSON input 错误？
答：今日诗词 API 可能不支持海外访问，这是今日诗词 API 的问题，并不是本插件的问题，暂时无法修复
### 切换间隔为什么没有提供每次打开时立即切换的功能？
答：本插件使用的是今日诗词提供的免费 API，存在流量限制，高频率切换会导致插件使用体验下降
### 除简体中文外，会支持其他语言吗？
答：暂时没有支持其他语言的计划
